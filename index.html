Math Widgets

Interactive classroom widgets. Each one is a single self-contained page — it can be opened directly, or embedded in another site with an iframe.

Number Set Nester

Drag numbers into the smallest set that will hold them — natural, whole, integer, rational, irrational, real. Generates a fresh set of twelve each round.

Number Set Venn

The nesting diagram on its own, with overlays showing how prime/composite, even/odd, and positive/negative relate to it.

Widgets accept options on the URL: ?title=0 hides the heading, ?reveal=0 shows all definitions from the start.
